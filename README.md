# Портфолио начинающего тестировщика ПО

Привет! Меня зовут Алина. Я начинающий тестировщик ПО, развиваюсь в направлении ручного тестирования и собираю здесь свои учебные и практические работы.

В этом портфолио будут собраны примеры тестовой документации, SQL-запросы, задания по API-тестированию, мобильному тестированию и другие материалы, которые показывают мои навыки в тестировании ПО.

## Что будет в портфолио

- Чек-листы
- Тест-кейсы
- Баг-репорты
- SQL-запросы
- API-тестирование в Postman
- Мобильное тестирование
- Сертификаты об обучении

## Навыки

- Ручное тестирование
- Составление тестовой документации
- Поиск и описание дефектов
- Работа с DevTools
- API-тестирование
- SQL
- Git и GitHub
- Основы мобильного тестирования

## Обо мне

Я прохожу обучение по тестированию ПО и постепенно собираю здесь свои практические работы.  
Мне интересно разбираться в логике работы приложений, находить ошибки и оформлять результаты тестирования понятно и аккуратно.

## Структура портфолио

| Раздел | Описание |
|---|---|
| checklists | Чек-листы для проверки функциональности |
| test-cases | Тест-кейсы с шагами и ожидаемым результатом |
| bug-reports | Примеры баг-репортов |
| sql | SQL-запросы из практических заданий |
| api-postman | Примеры API-тестирования |
| mobile-testing | Задания по мобильному тестированию |
