# Пример проверки запроса в Chrome DevTools

## Объект проверки

Вкладка Network в Chrome DevTools при авторизации пользователя на сайте или в веб-приложении.

## Цель проверки

Проверить, какой запрос отправляется при попытке авторизации, какой статус возвращает сервер и какие данные приходят в ответе.

## Шаги проверки

1. Открыть страницу авторизации.
2. Открыть Chrome DevTools с помощью клавиши F12 или сочетания Ctrl + Shift + I.
3. Перейти во вкладку Network.
4. Ввести логин и пароль в форму авторизации.
5. Нажать кнопку «Войти».
6. Найти в списке запрос, связанный с авторизацией.
7. Проверить метод запроса, статус ответа, заголовки и тело ответа.

## Что проверяется

| Проверка | Ожидаемый результат |
|---|---|
| Метод запроса | Используется подходящий метод, например POST |
| Статус ответа | При успешной авторизации возвращается статус 200 OK |
| Ошибочная авторизация | При неверных данных возвращается ошибка, например 400 или 401 |
| Заголовки запроса | Заголовки передаются корректно |
| Тело ответа | Ответ содержит понятную информацию о результате авторизации |
| Время ответа | Запрос выполняется за приемлемое время |

## Пример результата

При вводе неверного пароля запрос на авторизацию был отправлен, сервер вернул ошибку авторизации, а в ответе содержалась информация о том, что логин или пароль указаны неверно.

## Примечание

Такая проверка помогает понять, что происходит не только на странице приложения, но и на уровне обмена данными между клиентом и сервером.
