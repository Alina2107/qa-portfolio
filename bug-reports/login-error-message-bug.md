# Баг-репорт: Не отображается сообщение об ошибке при вводе неверного пароля

ID: BUG-001  
Раздел: Форма авторизации  
Серьёзность: Major  
Приоритет: High  
Статус: New  

## Описание

При попытке авторизации с валидным логином и неверным паролем пользователь не входит в систему, но сообщение об ошибке не отображается.

## Предусловия

Пользователь зарегистрирован в системе и находится на странице авторизации.

## Тестовые данные

Логин: valid_user@example.com  
Пароль: WrongPassword123

## Шаги воспроизведения

1. Открыть страницу авторизации.
2. Ввести валидный логин.
3. Ввести неверный пароль.
4. Нажать кнопку «Войти».

## Фактический результат

Пользователь не авторизуется, но сообщение об ошибке не отображается.

## Ожидаемый результат

Пользователь не авторизуется. На странице отображается понятное сообщение об ошибке, например: «Неверный логин или пароль».

## Окружение

- ОС: Windows 10 / Windows 11
- Браузер: Google Chrome
- Тип тестирования: функциональное тестирование

## Примечание

Отсутствие сообщения об ошибке может быть непонятно пользователю, так как он не видит причину неуспешной авторизации.
