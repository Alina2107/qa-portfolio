# Чек-лист проверки формы авторизации

## Объект тестирования

Форма авторизации пользователя на сайте или в веб-приложении.

## Проверки

| № | Проверка | Ожидаемый результат |
|---|---|---|
| 1 | Поля «Логин» и «Пароль» отображаются на странице | Пользователь видит оба поля ввода |
| 2 | Кнопка «Войти» отображается на странице | Пользователь видит кнопку входа |
| 3 | Пользователь может ввести данные в поле «Логин» | Введённые символы отображаются в поле |
| 4 | Пользователь может ввести данные в поле «Пароль» | Символы вводятся, пароль скрыт маской |
| 5 | Авторизация с валидным логином и паролем | Пользователь успешно входит в систему |
| 6 | Авторизация с неверным логином | Отображается сообщение об ошибке |
| 7 | Авторизация с неверным паролем | Отображается сообщение об ошибке |
| 8 | Авторизация с пустым полем «Логин» | Отображается сообщение о необходимости заполнить поле |
| 9 | Авторизация с пустым полем «Пароль» | Отображается сообщение о необходимости заполнить поле |
| 10 | Авторизация с пустыми полями «Логин» и «Пароль» | Отображается сообщение о необходимости заполнить обязательные поля |
| 11 | Проверка ограничения длины поля «Логин» | Система корректно обрабатывает слишком длинное значение |
| 12 | Проверка ограничения длины поля «Пароль» | Система корректно обрабатывает слишком длинное значение |
| 13 | Проверка ввода спецсимволов в поле «Логин» | Система корректно обрабатывает введённые спецсимволы |
| 14 | Проверка ввода пробелов в поля | Система корректно обрабатывает пробелы в начале и конце значения |
| 15 | Проверка работы кнопки «Показать пароль», если она есть | Пароль отображается или скрывается при нажатии |
| 16 | Проверка ссылки «Забыли пароль?», если она есть | Пользователь переходит на страницу восстановления пароля |
| 17 | Проверка ссылки регистрации, если она есть | Пользователь переходит на страницу регистрации |
| 18 | Проверка отображения сообщений об ошибках | Сообщения понятны пользователю и отображаются рядом с формой или полем |
| 19 | Проверка сохранения сессии после входа | После успешной авторизации пользователь остаётся в системе |
| 20 | Проверка выхода из аккаунта после авторизации | Пользователь может выйти из системы |

## Примечание

Чек-лист составлен для базовой проверки формы авторизации. Его можно адаптировать под конкретный сайт или приложение.
