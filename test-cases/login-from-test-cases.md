# Тест-кейсы для формы авторизации

## Объект тестирования

Форма авторизации пользователя на сайте или в веб-приложении.

## TC-001: Успешная авторизация с валидными данными

Предусловия:  
Пользователь зарегистрирован в системе.

Тестовые данные:  
Логин: valid_user@example.com  
Пароль: ValidPassword123

Шаги:
1. Открыть страницу авторизации.
2. Ввести валидный логин.
3. Ввести валидный пароль.
4. Нажать кнопку «Войти».

Ожидаемый результат:  
Пользователь успешно авторизован и попадает в личный кабинет.

---

## TC-008: Проверка ссылки «Забыли пароль?»

Предусловия:  
На форме авторизации есть ссылка «Забыли пароль?».

Шаги:
1. Открыть страницу авторизации.
2. Нажать на ссылку «Забыли пароль?».

Ожидаемый результат:  
Пользователь переходит на страницу восстановления пароля.
